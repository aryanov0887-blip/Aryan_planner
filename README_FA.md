# برنامه‌ریز من — پروژه اندروید اولیه

## این پروژه چه دارد؟
- برنامه اندروید بومی با رابط فارسی
- ثبت کارها با آیکون، تاریخ، ساعت، مدت و یادآوری
- ذخیره محلی کارها
- اعلان‌های زمان‌دار اندروید (نیازمند اجازه اعلان)
- تلاش برای دریافت مسابقات آینده رئال مادرید از ESPN

## ساخت APK بدون نصب Android Studio روی گوشی
1. یک حساب GitHub بساز یا وارد حساب شو.
2. یک repository جدید بساز و فایل‌های داخل ZIP را در آن آپلود کن (پوشه `.github` هم باید آپلود شود).
3. وارد تب Actions شو؛ workflow با نام `Build Android APK` را اجرا کن یا پس از push خودش اجرا می‌شود.
4. وقتی اجرا تمام شد، در صفحه اجرای workflow پایین بخش Artifacts، فایل `aryan-planner-debug-apk` را دانلود کن.
5. ZIP آرتیفکت را روی گوشی باز کن تا `app-debug.apk` را ببینی و نصبش کنی. ممکن است اندروید اجازه نصب از مرورگر/فایل‌منیجر را بخواهد.

## نکات مهم
- این نسخه اولیه است و در این محیط کامپایل و روی دستگاه واقعی آزمایش نشده.
- تاریخ ورودی در نسخه فعلی با قالب میلادی `YYYY-MM-DD` وارد می‌شود؛ تاریخ‌های نمایشی شمسی هستند. نسخه بعدی باید انتخاب‌گر تاریخ شمسی واقعی داشته باشد.
- دریافت مسابقات ممکن است به پوشش API عمومی ESPN و اتصال اینترنت وابسته باشد.
- اعلان‌های کار با AlarmManager برنامه‌ریزی می‌شوند؛ بعضی گوشی‌ها برای عملکرد قابل اتکا در پس‌زمینه به تنظیمات باتری/اجازه‌های اضافی نیاز دارند. پس از راه‌اندازی مجدد گوشی، آلارم‌ها در این نسخه بازیابی نمی‌شوند.
- اعلان خودکار بازی‌های رئال در این نسخه هنوز به فهرست کارها اضافه نشده؛ این بخش باید در گام بعدی پیاده‌سازی شود.
- برای انتشار عمومی باید امضای release و بررسی امنیتی/سازگاری انجام شود.
